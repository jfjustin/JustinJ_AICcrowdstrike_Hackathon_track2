What this is

A mini "Charlotte AI": it ingests a correlated alert queue built from the AIT Alert Data Set (AMiner IDS alerts across 8 attack scenarios), ranks incidents, explains them in plain English via an LLM, and learns from analyst feedback to suppress repeat false positives.

Pipeline

55,558 raw alerts → 21,251 deduped representatives → 1,395 correlated chains, ranked by chain_score = max_severity × (1 + 0.5·log10(n)) so burst incidents outrank lone noisy alerts. Ground-truth labels are used only to compute the metrics on the Metrics tab — never shown next to an individual chain unless "eval mode" is on.

Honest caveats

  • Per-alert severity ranking alone has weak precision — benign high-entropy DNS queries score 90 and float to the top. The correlation + feedback-loop suppression is what beats that baseline.
  • A few exfil-like DNS bursts fall outside the labeled attack windows — the LLM explanation and analyst verdict are the arbiter for those, same as a real SOC.

Explain providers

Private/local — Ollama running deepseek-r1:8b on this machine, no data leaves the box. Cloud — Anthropic API; paste a key into the chatbox in the detail panel, it's used for one request and kept only in this browser tab's session storage.
